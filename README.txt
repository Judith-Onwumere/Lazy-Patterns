LAZY PATTERNS – install as an app (PWA)

A PWA must be served over HTTPS, so upload this whole folder to any free static host:
  • Netlify Drop (app.netlify.com/drop) – drag this folder onto the page
  • GitHub Pages, Vercel or Cloudflare Pages – upload the files as they are
Then open the web address in Chrome (Android) or Safari (iPhone/iPad):
  Chrome: menu ⋮ > Install app (or tap "Install app" in the app's left menu)
  Safari: Share > Add to Home Screen

Keep all files together: index.html, manifest.webmanifest, sw.js and the icon files.
Patterns are saved in the browser on each device/address. To move patterns from the old
single-file version, use "Back up all patterns" there and "Import a pattern" in the installed app.
